# exampleExpo (legacy)

This demo targets **Expo SDK 45** and is kept for reference only.

For new projects, install `react-native-page-flipper` in your own Expo app and follow the root `README.md`.

To try the local package from this example:

```sh
cd exampleExpo
yarn install
yarn start
```

The example expects `react-native-page-flipper` to resolve from the parent directory.
